APL in WebAssembly

A word-glyph APL interpreter written in portable C89, compiled to WASM. Glyphs are spelled as words: iota, rho, reduce plus. It runs in this page with no server.

Workspace


      
   

    

    
Variables and functions persist for the session because each line replays the history on a fresh VM (fast for a session this size). ? and roll reseed on every replay, so keep random numbers in the line that uses them.
